⚙️  CONFIGURATION FILES
═══════════════════════════════════════════════════════════════════════════════

PHP Application .env:
    Location: /var/www/mxa-ocr-app/current/php-app/.env
    
    Critical values:
    • APP_KEY (generate: openssl rand -hex 32)
    • KEYCLOAK_CLIENT_SECRET (from Keycloak admin console)
    • DB_PASSWORD
    • MINIO_ACCESS_KEY
    • MINIO_SECRET_KEY

Python Backend .env:
    Location: /opt/apps/mxa-ocr/python-backend/.env
    
    Critical values:
    • DB_PASSWORD (same as PHP)
    • MINIO_ACCESS_KEY (same as PHP)
    • MINIO_SECRET_KEY (same as PHP)
    • REDIS_PASSWORD (if Redis has auth)

🔧 KEYCLOAK CONFIGURATION
═══════════════════════════════════════════════════════════════════════════════

1. Login to Keycloak:
   http://192.168.1.59:8080/admin

2. Create new client:
   • Client ID: mxa-ocr-web
   • Client Protocol: openid-connect
   • Access Type: confidential
   • Valid Redirect URIs: https://ocr.gismartanalytics.com/auth/callback
   • Web Origins: https://ocr.gismartanalytics.com

3. Copy Client Secret from Credentials tab

4. Update PHP .env:
   ssh root@192.168.1.66
   nano /var/www/mxa-ocr-app/current/php-app/.env
   # Set: KEYCLOAK_CLIENT_SECRET=<your-secret>

5. Restart Apache:
   systemctl reload apache2

🚨 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Service won't start:
    journalctl -u <service-name> -n 100 --no-pager

Database connection failed:
    psql -U mxa_ocr_user -d mxa_ocr -h localhost

API not responding:
    netstat -tlnp | grep 8100
    curl http://localhost:8100/api/v1/health

Permission errors:
    # PHP: chown -R www-data:www-data /var/www/mxa-ocr-app
    # Python: chown -R mxa-ocr:mxa-ocr /opt/apps/mxa-ocr
